# ADR 0004: Versioned consent

**Status:** Accepted · 2026-10-08

Store explicit health-processing and contact-sharing choices with the privacy-policy version and timestamp. Donor matching requires current active consent; interest shares contact details only after the donor acts. Withdrawal disables matching and removes outstanding interests. A policy update changes the shared version and requires renewed consent. Legal retention and local consent wording still need review before real use.
