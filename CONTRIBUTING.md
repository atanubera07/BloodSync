# Contributing

Thanks for helping BloodSync. This project handles sensitive coordination data, so please open an issue before large changes. Never include real patient or donor information in issues, tests, screenshots, or logs.

## Local setup

Follow [README.md](README.md). Run `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`, `pnpm build`, and the integration script before a pull request. Add meaningful ownership and role tests for API changes. Use conventional commits such as `fix(api): ...`.

Report vulnerabilities through [SECURITY.md](SECURITY.md), not public issues. We expect everyone to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
