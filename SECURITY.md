# Security policy

Do not publish vulnerabilities or personal data in an issue. Use **GitHub → Security → Report a vulnerability** on `atanubera07/BloodSync` to send a private report. Include affected commit, reproduction steps using synthetic data, impact, and a suggested fix if known. The maintainer will acknowledge and coordinate a fix and disclosure. No response time or bounty is promised.

This code is under development and has not had an independent security or clinical review. Do not use it with real patient or donor data.
