# Security policy

## Supported versions

Only the latest `main` branch and the latest tagged release receive security fixes. Earlier versions are unsupported. This prototype has not passed independent security or clinical review and must not process real patient or donor data.

## Private reporting

Use **GitHub → Security → Report a vulnerability** on `atanubera07/BloodSync`. Do not file a public issue or include personal data. Give the affected commit, impact, and reproduction steps using synthetic data.

The maintainer aims to acknowledge a report within **7 calendar days** and give an initial triage update within **30 calendar days**. These are response targets, not a guaranteed fix or bounty. The maintainer will coordinate disclosure with the reporter after a fix or mitigation is available.
